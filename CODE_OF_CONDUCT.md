# Code of Conduct

Praxis AI follows the [CNCF Code of Conduct][cncf-coc], consistent with
Praxis core.

To report an issue, contact the [Praxis maintainers][maintainers] or the
[CNCF Code of Conduct Committee][conduct-email].
