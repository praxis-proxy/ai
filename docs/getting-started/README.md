# Get started

Run Praxis AI, send a first request, and choose the client protocol and
provider path for your deployment. Read these pages in order:

1. [Quickstart](quickstart.md): run the published container image and forward
   an OpenAI Responses request.
2. [Choose a client and provider](choose-client-and-provider.md): protocol,
   credentials, feature selection, and compatibility limits in one table.
3. [Build from source](build-from-source.md): build the binary, check the
   default responder, and forward Responses and Chat Completions requests.

Then continue with the task [guides](../guides/README.md).
